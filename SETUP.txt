================================================================================
  GORILLA PATERNITY ANALYSIS — VS CODE SETUP GUIDE
  Non-Invasive Paternity & Kinship Analysis in Wild Mountain Gorillas
================================================================================

PREREQUISITES
─────────────
1. VS Code: https://code.visualstudio.com/
2. Python 3.10+: https://www.python.org/downloads/
3. Git (optional): https://git-scm.com/

STEP 1 — OPEN THE PROJECT
──────────────────────────
  File → Open Folder → select "gorilla-paternity-analysis/"


STEP 2 — INSTALL VS CODE EXTENSIONS (ONE-TIME)
───────────────────────────────────────────────
  In VS Code Extensions panel (Ctrl+Shift+X), search and install:
    • Python         (Microsoft)
    • Jupyter        (Microsoft)
    • Pylance        (Microsoft)


STEP 3 — CREATE PYTHON ENVIRONMENT
────────────────────────────────────
  Open Terminal in VS Code (Ctrl+` or View → Terminal)

  Option A — Conda (recommended):
    conda env create -f environment.yml
    conda activate gorilla-paternity

  Option B — pip + venv:
    python -m venv .venv
    # Windows:
    .venv\Scripts\activate
    # macOS/Linux:
    source .venv/bin/activate
    pip install -r requirements.txt


STEP 4 — SELECT THE KERNEL
────────────────────────────
  Open any .ipynb notebook.
  Top-right → "Select Kernel" → Python Environments → gorilla-paternity
  (or .venv if you used Option B)


STEP 5 — GENERATE THE DATASET
───────────────────────────────
  In VS Code Terminal (with env active):
    python scripts/data_generator.py

  This creates:
    data/raw/individuals.csv
    data/raw/genotypes.csv
    data/raw/genotypes_true.csv
    data/raw/allele_frequencies.csv
    data/raw/groups.csv

  — OR — let Notebook 01 generate it automatically (Cell 2 does this).


STEP 6 — RUN NOTEBOOKS IN ORDER
─────────────────────────────────
  Open each notebook and run all cells: Ctrl+Shift+P → "Run All Cells"

  01_data_import_and_qc.ipynb       ~2 min
  02_population_genetics.ipynb      ~2 min
  03_parentage_analysis.ipynb       ~5 min  (LOD scoring, O(n²))
  04_kinship_analysis.ipynb         ~5 min  (pairwise relatedness, O(n²))
  05_results_and_conservation.ipynb ~3 min

  Total runtime: ~15–20 minutes


STEP 7 — FIND YOUR OUTPUTS
────────────────────────────
  outputs/figures/    ← All PNG plots (publication-quality, 200 DPI)
  outputs/tables/     ← All CSV result tables
  data/processed/     ← QC-filtered data, pairwise relatedness matrix

REAL DATA — WHERE TO GET IT
─────────────────────────────
  Replace data/raw/*.csv with real data matching the column schema in README.md

  Sources:
  • Dryad Digital Repository
    https://datadryad.org  → search "Gorilla beringei microsatellite"

  • Bradley et al. (2004) — Virunga gorilla genetics
    Am J Primatol 62:1-14

  • Nsubuga et al. (2010) — Gorilla microsatellite panel
    Mol Ecol Resour 10:397-399

  • NCBI PopSet
    https://www.ncbi.nlm.nih.gov/popset → search "gorilla STR"

  Schema required (genotypes.csv):
    individual_id, {LOCUS}_a1, {LOCUS}_a2  (one pair per locus, 15 loci)

  Schema required (individuals.csv):
    individual_id, sex, age_class, group_id, dominance_rank,
    mother_id, true_father_id (set to None if unknown)


TROUBLESHOOTING
────────────────
  "Module not found":
    → Make sure your environment is active and requirements are installed
    → Check that VS Code is using the correct kernel

  "FileNotFoundError: data/raw/individuals.csv":
    → Run: python scripts/data_generator.py
    → Or run Cell 2 of Notebook 01

  Notebook runs slowly:
    → The pairwise relatedness step (NB04) is O(n²); ~50 individuals ≈ 1 min
    → For large datasets (>200 ind), consider parallelisation

  Kernel crashes:
    → Close other notebooks; each notebook loads large matrices
    → Increase memory if running on <8 GB RAM
